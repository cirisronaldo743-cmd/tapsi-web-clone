# tapsi-web-clone
💻⚡ An educational and practice version of the Tapsi website built with HTML and advanced CSS. 💻⚡

🚕 Tapsi Clone

⚡ Technologies

- HTML5
- CSS3

✨ Features

- 📱 Responsive Design
- 🧩 Semantic HTML
- 🎨 Modern UI Design
- 🖱️ UX/UI Improvements
- 🔄 CSS Transitions & Animations
- 📦 Flexbox
- 🗂️ CSS Grid

🎨 UX/UI

The interface was designed with a focus on visual consistency, usability, spacing, colors, buttons, and interactive elements.

Hover effects, transitions, animations, and visual feedback were also used to make interactions smoother and more engaging.

📱 Responsive Design

The website was tested across different screen sizes, including desktop, tablet, and mobile layouts, to provide a consistent experience across devices.
